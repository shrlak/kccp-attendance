# 06. 키오스크 운영 가이드

**대상**: 주일 출석 데스크 담당자 (관리자 권한 필요 — 리더/새가족팀/최고관리자. 목사님 계정은 키오스크 불가)

키오스크는 교회 입구 태블릿에 띄워 놓는 **큰 버튼 출석 화면**입니다.
부원 이름을 누르면 바로 출석 처리되며, 시간·위치 제한이 없습니다.

## 예배 전 세팅

1. 태블릿에서 앱 접속 → **관리자** → 로그인.
2. 상단의 **키오스크** 버튼 → 전체 화면 키오스크 진입.
3. 헤더에 "출석 키오스크"와 오늘 출석 인원이 보이면 준비 완료.
4. 태블릿을 입구 데스크에 비치. (화면 자동 잠금은 길게 설정 권장)

> 키오스크 화면은 새로고침해도 유지됩니다. 명단은 30초마다 자동 갱신됩니다.

## 기본 사용법 — 이름 눌러 출석

- 명단이 부서별로 구분되어 표시됩니다 (대학부=노랑, 청년부=파랑, 기타=회색).
- 부원 **이름 버튼을 탭** → 출석 완료 표시.
- 이미 출석한 부원은 **초록 체크**가 붙어 있고, 다시 누르면 "이미 출석" 안내가 뜹니다.
- 사람이 많으면 상단 **🔍 이름 검색** 칸에 입력해 바로 찾으세요.

## 하단 버튼 2개

### 👋 게스트 체크인
- 일회성 방문자용. 이름만 입력하면 오늘 출석이 방문자(visitor)로 기록됩니다.
- 정식 멤버가 만들어지지 않으므로 "그냥 한번 와본" 분께 부담 없이 사용하세요.

### ✝️ 새가족 등록
- 정식 등록을 원하는 새가족용. 등록 카드(이름, 부서, 동산, 성별, 연락처, 카톡 ID, 생일, 세례, 학교, 신앙 기간, 등록일, 심방 요청)를 작성합니다.
- 저장 시 멤버 생성 + **오늘 첫 출석 🌟** 이 자동 기록되고, 「새가족」 탭 관리 목록에 들어갑니다.
- 가능하면 새가족팀과 함께 응대하세요 ([03 새가족팀 매뉴얼](./03-새가족팀용.md)).

## 키오스크 종료

- 헤더의 **종료** 버튼 → 관리자 비밀번호 입력 → 종료.
- 비밀번호를 요구하는 이유: 부원이 실수로(또는 장난으로) 키오스크를 빠져나가는 것을 막기 위해서입니다.

## 문제 해결

| 상황 | 조치 |
|---|---|
| 명단에 이름이 없음 | 👋 게스트로 우선 출석 처리 → 예배 후 관리자 화면 「기기」/「멤버」에서 정식 등록 |
| 인터넷 끊김 | 잠시 후 자동 복구. 안 되면 와이파이 확인 후 새로고침 |
| 잘못 눌러 다른 사람 출석 처리됨 | 관리자 화면 「멤버」 → 해당 멤버 → 출석 이력에서 오늘 기록 삭제 |
| 화면이 잠겼거나 닫힘 | 다시 접속해 관리자 로그인 → 키오스크 재진입 |

## 예배 후 마무리

1. 키오스크 종료 (비밀번호).
2. 관리자 화면 「오늘」 탭에서 출석 누락 확인 → 수동 출석 보정.
3. 필요 시 「출석부」 → 내보내기 → **카카오톡 요약** 복사해 보고.
