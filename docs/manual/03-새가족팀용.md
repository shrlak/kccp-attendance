# 03. 새가족팀용 매뉴얼

**대상**: `새가족팀(welcoming)` 역할이 부여된 팀원

새가족팀은 리더와 거의 같은 화면(오늘 · 출석부 · 멤버 · 통계 · 새가족 · 기기)을 보며,
**새가족 등록과 정착 관리**가 핵심 업무입니다. 보이는 범위는 본인에게 지정된 부서·동산 기준입니다.

## 로그인

[02 리더용 매뉴얼](./02-리더용.md)의 로그인 방법과 동일합니다.
(첫 화면 → **관리자** → Google 로그인 또는 비밀번호 입장. 권한 문제는 최고관리자에게 문의)

---

## 핵심 업무 1: 새가족 현장 등록 (주일)

처음 오신 분은 **키오스크**에서 바로 등록하는 것이 가장 좋습니다.

1. 키오스크 하단의 **✝️ 새가족 등록** 버튼.
2. 등록 카드 작성: 이름, 부서, 동산, 성별, 전화번호, 카카오톡 ID, 생일, 세례 여부, 학교, 신앙 기간, 등록일, **심방 요청** 여부.
3. 저장하면 멤버 생성 + **오늘 출석(첫 출석 🌟)** 이 자동으로 함께 기록됩니다.

> 아직 등록을 원치 않는 단순 방문자는 **👋 게스트 체크인**으로 이름만 받아 출석만 기록하세요.
> 나중에 등록을 원하면 그때 새가족 등록을 하면 됩니다.

키오스크 전반의 사용법은 [06 키오스크 운영 가이드](./06-키오스크-운영.md) 참고.

## 핵심 업무 2: 「새가족」 탭 — 정착 관리

- **이번 학기 새가족 목록**: 이번 학기에 등록한 멤버가 자동으로 모입니다 (학기 배지 표시, 예: "2026 봄학기").
- 각 새가족 행에서:
  - **교육 1주차 / 교육 2주차** 체크박스 — 새가족 교육 수료 여부를 표시.
  - **🙏 심방 요청** 표시 — 등록 시 심방을 요청한 분. 목사님·리더와 공유해 심방을 진행하세요.
  - 등록일, 전화번호 표시.
- **월별 등록 현황**: 지난 학기 새가족들이 월별로 정리되어 보입니다.

## 핵심 업무 3: 새가족 정보 보완

「멤버」 탭에서 해당 멤버 카드 클릭 → 수정:
- 누락된 연락처, 생일, 카카오톡 ID, 메모(기도제목 등) 입력.
- 새가족 기간이 끝나면 **새가족 체크박스를 해제**해 일반 멤버로 전환.
- 본인 폰으로도 출석하기 시작해 중복 멤버가 생겼다면 **병합** 기능으로 정리 (출석 기록이 합쳐짐, 되돌릴 수 없음).

## 그 외 가능한 일

- 「오늘」 탭에서 **수동 출석** 처리 (새가족이 체크인을 어려워할 때).
- 「기기」 탭에서 새가족의 휴대폰을 멤버에 **연결** — 다음 주부터는 본인 폰으로 직접 체크인할 수 있게 해주세요.
- 「통계」 탭의 월별/학기별 **첫 출석(새가족) 수** 확인 — 새가족 보고에 활용.

## 새가족팀이 할 수 없는 일

- 동산 일괄 이동, 출석 전체 삭제(요청만 가능), 설정/동산/관리자 탭 접근.

---

## 새가족 응대 흐름 (추천)

1. **주일**: 새 얼굴 발견 → 인사 → 키오스크 ✝️ 새가족 등록 (심방 요청 여부 꼭 확인).
2. **당일/주중**: 「새가족」 탭에서 등록 확인 → 환영 연락 (전화번호/카톡 ID 활용).
3. **교육 기간**: 교육 1·2주차 진행 시마다 체크박스 표시.
4. **다음 주일**: 본인 휴대폰으로 체크인하도록 안내 (기기 연결 도와주기).
5. **학기말**: 새가족 정착 현황을 통계와 함께 보고.
