# 05. 최고관리자(임원) 매뉴얼

**대상**: `최고관리자(super_admin)` — 회장단·임원·시스템 총괄

최고관리자는 모든 기능을 쓸 수 있고, 리더에게 없는 세 개의 탭이 추가로 보입니다:
**관리자 · 동산 · 설정**. 리더 공통 기능(오늘/출석부/멤버/통계/새가족/기기)은
[02 리더용 매뉴얼](./02-리더용.md)을 보세요. 이 문서는 최고관리자 전용 기능을 다룹니다.

---

## 「설정」 탭

### 출석 가능 시간
- **요일 선택**: 일–토 버튼 토글 (최소 1개).
- **시간**: 시작/종료 시각(24시간제). 예: 13:00–15:00.
- 이 시간 밖에는 개인 휴대폰 체크인이 차단됩니다 (키오스크/수동 출석은 항상 가능).

### 공지사항
- 입력한 내용이 첫 화면과 체크인 결과 화면의 금색 "공지" 박스에 표시됩니다.

### 모드 3종
| 모드 | 켜면 |
|---|---|
| **여름 모드 (합동)** | 대학부·청년부 동산이 합쳐지고, KM 리더들이 두 부서를 모두 보게 됩니다. 동산 탭도 합동 명단으로 전환. |
| **개인 체크인** | 첫 화면에 체크인 버튼이 나타나 부원이 직접 출석할 수 있습니다. 끄면 키오스크 전용 운영. |
| **데모 모드** | 요일·시간·위치 제한이 전부 해제됩니다. **시연/테스트용 — 평상시에는 반드시 꺼두세요.** |

---

## 「동산」 탭

### 동산 이름 관리
- 부서별(대학부/청년부/EM/Adult Ministry)로 동산 이름 목록을 추가/삭제.
- **여름 모드 중에는** 합동 명단 하나로 편집하며, 대학부·청년부 양쪽에 동일하게 적용됩니다 (☀️ 경고 배너 표시).
- **저장** 버튼을 눌러야 반영됩니다.

### 동산지기 👑 / 부동산지기 ⭐ 지정
- 부서+동산별로 멤버를 검색해 동산지기/부동산지기를 지정.
- 멤버 카드와 「오늘」 목록에 배지로 표시됩니다.
- **표시용 배지일 뿐 권한과 무관**합니다. 단, 동산지기/부동산지기로 지정된 리더는 동산 일괄 이동과 출석 삭제 요청이 막힙니다 (이해충돌 방지).

## 「관리자」 탭 — 권한·승인·감사·백업

### 관리자 명단 (역할 부여/회수)
- 현재 관리자 목록: 이름, 역할(최고관리자/리더/목사님/새가족팀), 부서, 동산, 사역.
- **관리자 추가**: 멤버 검색 → 역할 선택 → 범위(부서/동산) 지정.
  - 리더·새가족팀은 반드시 부서·동산 범위를 지정하세요 — 그 범위만 보게 됩니다.
  - Google 로그인을 쓰게 하려면 「멤버」 탭에서 해당 멤버에 **이메일**도 등록해 주세요.
- **제거**: 역할 회수. 마지막 남은 최고관리자는 제거할 수 없습니다(잠금 방지).

### 등록 승인 대기열
- **등록 승인제** 스위치를 켜면, 부원의 휴대폰 자가등록이 즉시 멤버가 되지 않고 대기열로 들어옵니다.
- 대기 항목(기기 ID, 이름, 부서, 동산, 신청 시각)을 **승인**(멤버 생성·연결) 또는 **거절**.
- 관리자 탭 아이콘에 대기 건수 배지가 표시됩니다.

### 출석 전체 삭제 — 승인 절차
- 리더/새가족팀이 보낸 삭제 요청이 여기 표시됩니다 (요청자, 시각).
- **승인 후 삭제**: 전체 출석 기록 삭제 (복구 불가!) / **거절**: 요청만 폐기.
- 최고관리자 본인은 「출석부」 탭에서 즉시 삭제할 수 있습니다 — 학기 리셋 등 꼭 필요할 때만, **반드시 백업을 먼저** 받으세요.

### 감사 로그
- **감사 로그 불러오기** 버튼 → 최근 100건의 관리 작업 (시각, 작업, 관리자, 상세).
- 로그인, 설정 변경, 멤버 수정/병합, 기기 등록/연결, 출석 추가/삭제, 권한 변경, 복원 등 모든 민감 작업이 기록됩니다. 문제가 생기면 여기서 먼저 추적하세요.

### 백업 / 복원
- **백업 다운로드**: 전체 데이터 JSON 스냅샷 (`kccp-backup-날짜.json`). **매주 또는 큰 작업 전마다** 받아두기를 권장합니다.
- **복원**: 백업 파일 선택 → 2단계 확인 → **모든 데이터가 백업 시점으로 덮어쓰기**됩니다. 비상시에만 사용.

### 전체 백업 (오프사이트)
- **백업 저장 공간**: 현재 사용량이 한도(기본 10 GB) 대비 막대와 퍼센트로 표시됩니다. 주간 백업 하나만 보관하므로 평소에는 1% 미만입니다.

## 자주 하는 운영 작업 절차

### 새 리더 임명
1. 그 사람이 멤버로 등록되어 있는지 「멤버」에서 확인 (없으면 「기기」에서 등록).
2. Google 로그인용 이메일을 멤버 정보에 입력.
3. 「관리자」 → 관리자 추가 → 역할 `리더` + 부서·동산 범위 지정.
4. 본인에게 로그인 방법 안내 ([02 리더용](./02-리더용.md) 전달).

### 학기 전환 (예: 여름 합동 시작)
1. 백업 다운로드.
2. 「설정」에서 여름 모드 ON.
3. 「동산」에서 합동 동산 이름 정리, 동산지기 재지정.
4. 「멤버」에서 동산 일괄 이동으로 부원 배치.

### 출석 시간 임시 변경 (특별 행사)
1. 「설정」에서 요일/시간 변경 → 저장.
2. 행사 후 원래대로 복구. (현장에서만 받을 거면 개인 체크인을 끄고 키오스크로 운영해도 됩니다)

### 부원이 폰을 바꿨어요
「기기」 탭 → **기기 연결** → 새 기기 ID + 기존 멤버 검색 → 연결. 출석 기록 유지됨.

### 중복 멤버 정리
「멤버」 → 카드 열기 → **병합** → 남길 멤버 선택. (되돌릴 수 없음 — 백업 먼저!)

---

## 운영 수칙 (권장)

- 데모 모드는 시연 직후 바로 끄기.
- 전체 삭제·복원·병합 전에는 항상 백업.
- 최고관리자는 최소 2명 유지 (한 명이 연락 두절돼도 운영 가능하도록).
- 마스터 비밀번호는 단톡방에 올리지 말고 필요한 사람에게 개별 전달. 유출 의심 시 시스템 담당자에게 변경 요청.
- 학기마다 「관리자」 명단을 점검해 더 이상 섬기지 않는 사람의 역할 회수.
